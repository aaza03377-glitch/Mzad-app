# نظام إدارة مزاد ركن الكهرم — PWA V14

## الإصلاحات الجديدة

1. التحصيل وتسوية البائع أصبحت تُربط بالجلسة والبيعة التي يحددها المستخدم، ولا تنتقل تلقائياً إلى أقدم جلسة.
2. نافذة التحصيل والتسوية تعرض جميع البيعات المستحقة مع اسم الجلسة والمبلغ المتبقي، ويمكن توزيع العملية يدوياً على أكثر من بيعة.
3. عدد المرتجعات والإلغاءات في بطاقة العميل يُحتسب على المشتري فقط، ولا يظهر على بطاقة البائع.
4. إضافة زر «التراجع عن الإرجاع / الإلغاء» من تفاصيل العملية، مع عكس حركات المحافظ وإعادة البيعة إلى حالتها السابقة.
5. الاحتفاظ بسجل تدقيق لعملية الإرجاع بعد التراجع عنها.

## التحديث على GitHub

استبدل جميع ملفات النسخة السابقة، خصوصاً index.html وmanifest.webmanifest وsw.js، وارفع مجلدي icon وassets كما هما.
قبل التحديث صدّر نسخة احتياطية من بيانات النظام.
