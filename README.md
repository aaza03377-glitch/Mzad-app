# نظام إدارة المزاد – نسخة PWA V10

هذه النسخة تحول النظام إلى تطبيق ويب تقدمي يمكن تثبيته من رابط GitHub Pages وفتحه من أيقونة مستقلة بدون شريط عنوان المتصفح.

## الملفات الضرورية

يجب رفع جميع الملفات والمجلدات مع الحفاظ على أسمائها ومواقعها:

- `index.html`
- `manifest.webmanifest`
- `sw.js`
- `.nojekyll`
- مجلد `icons`

في نسخة المشروع المنظمة توجد أيضاً مجلدات `css` و`js` ويجب رفعها بالكامل.

## التثبيت على أندرويد

1. افتح رابط GitHub Pages في Google Chrome.
2. انتظر ظهور زر **تثبيت التطبيق** أعلى النظام، أو افتح قائمة Chrome.
3. اختر **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**.
4. افتح النظام لاحقاً من الأيقونة الجديدة.

عند فتحه من الأيقونة يعمل في وضع مستقل بدون شريط عنوان الموقع.

## التحديث من GitHub

بعد استبدال الملفات ورفعها إلى GitHub، افتح التطبيق مع اتصال بالإنترنت. سيظهر تنبيه عند توفر نسخة أحدث. اضغط **تحديث الآن** بعد حفظ العمل.

## التشغيل دون إنترنت

بعد فتح الموقع مرة واحدة مع اتصال بالإنترنت، يتم حفظ ملفات التطبيق الأساسية ويصبح بالإمكان فتحه دون إنترنت. البيانات نفسها تبقى محفوظة في `LocalStorage` على الجهاز.

## تنبيه البيانات

- بيانات كل جهاز مستقلة ولا تتم مزامنتها مع الأجهزة الأخرى.
- حذف بيانات Chrome أو إزالة التطبيق مع حذف بيانات الموقع قد يؤدي إلى فقد البيانات.
- صدّر نسخة احتياطية من داخل النظام بصورة دورية.

## تحديث V10 — قسم العملاء

- صندوق بحث فوري باسم العميل أو رقم الجوال، مع دعم الرمز المرجعي للعملاء بلا رقم.
- عرض العملاء في بطاقات مختصرة ومتجاوبة.
- كل بطاقة تعرض: الاسم، رقم الجوال أو الرمز الداخلي، عدد البيعات كبائع، عدد المشتريات، عدد الفرقيات، عدد المرتجعات، وعدد الإلغاءات.
- الإبقاء على ملخص المبالغ المستحقة للعميل أو المطلوبة منه، مع أزرار كشف الحساب والتعديل.
